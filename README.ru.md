# Учебная платформа

Личный проект для портфолио: платформа, на которой можно знакомиться с курсами программирования и учиться в своём темпе. Доступны русский и английский языки, светлая и тёмная темы. Интерфейс адаптирован для телефонов и компьютеров.

## Что можно попробовать

- Просмотреть каталог и найти интересующий курс.
- Открыть курс и изучить его уроки.
- Сменить язык или тему оформления в верхнем меню.

## Последние дополнения

Регистрация, вход, профиль ученика и полный курс JavaScript из десяти уроков реализованы и проверены локально. В курс входят примеры, упражнения, решения и итоговый проект. Эти дополнения ещё предстоит опубликовать в демоверсии.

Остальные курсы содержат демонстрационные программы занятий. Сохранение прогресса и восстановление пароля запланированы.

## Для разработчиков

Проект создан с использованием React, Next.js, TypeScript, NestJS и PostgreSQL. Инструкции по запуску и проверкам — в [руководстве разработчика](docs/DEVELOPMENT.md), по публикации — в [руководстве по развёртыванию](docs/DEPLOYMENT.md). Оба руководства на английском языке.
