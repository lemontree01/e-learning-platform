# Learning platform

A personal portfolio project that helps people explore programming courses and learn at their own pace. Available in English and Russian, with layouts for phones and computers and a choice of light or dark appearance.

## Explore the demo

- Browse and search the course catalog.
- Open a course to explore its lessons.
- Switch language or appearance from the top menu.

## Latest additions

Registration, sign-in, learner profiles, and a complete ten-lesson JavaScript course are implemented and tested locally. The course includes examples, exercises, solutions, and a final project. These additions still need to be deployed to the live demo.

The other 19 courses are marked as coming soon and list their planned topics. Course and lesson pages are rendered on the server, with their own titles and real 404s. Saved learning progress and password recovery are planned.

## For developers

Built with React, Next.js, TypeScript, NestJS, and PostgreSQL. See the [developer guide](docs/DEVELOPMENT.md) for setup and checks, and the [deployment guide](docs/DEPLOYMENT.md) for publishing instructions.
